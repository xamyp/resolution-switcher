# Resolution Switcher

Switch your screen resolution and refresh rate with one key.

- **Short press**: next mode of your list.
- **Long press (0.7 s)**: back to the original resolution.

Setup: drag **Cycle resolution** onto a key, pick modes in the settings panel and press **+**.

Requirements: Windows 10/11, Stream Dock software 3.10.188.226 or newer.
Logs: `plugin/log/plugin.log`

Documentation, source code and issues: https://github.com/xamyp/resolution-switcher
