# Changelog

## 1.0.0 — 2026-10-22
First public release.

- **Cycle resolution** action: each short press switches to the next mode of your list.
- Long press (0.7 s) restores the original resolution.
- Cycle list built from the modes Windows reports for the selected screen (resolution + refresh rate), with add, reorder and remove.
- Live key display of the current mode and its position in the list.
- Screen selection (primary screen by default, or any attached screen).
- Apply mode: permanent (like Windows Settings) or temporary (until reboot).
- Scaling option: driver default, stretch or center.
- English and French user interface.
